\# Project Overview



\## Selected Application

Invoice Ninja – Open Source Invoice \& Billing Application



\## Technology Stack

\- PHP (Laravel Framework)

\- MySQL Database

\- RESTful API

\- Web-based Frontend



\## Reason for Selection

\- Manages sensitive financial data

\- Contains authentication and authorization mechanisms

\- Suitable for OWASP Top 10 security testing

\- Actively maintained open-source project



\## Planned Phases

1\. Local Deployment

2\. Threat Modeling

3\. Automated Security Testing

4\. Manual Security Testing

5\. Vulnerability Remediation

6\. Retesting \& Documentation
